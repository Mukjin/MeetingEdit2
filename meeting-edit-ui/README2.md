# Meeting Edit UI

회의/세미나 녹화 영상을 AI가 자동으로 분석해서 편집해주는 웹 애플리케이션.
사회자 구간을 제거하고 발표자 화면공유 구간만 추출합니다.

---

## 어떤 문제를 해결하나

1시간 30분짜리 회의 녹화 영상을 편집하려면 직접 타임라인을 보면서 자르고 붙이는 작업이 필요합니다.
이 앱은 그 과정을 자동화합니다.

- 트랜스크립트를 AI가 읽고 **어떤 구간을 남길지 스스로 판단**
- 발표자별로 구간을 자동 감지하고 EDL(편집 결정 목록) 생성
- 사용자는 결과를 검토하고 수정한 뒤 렌더 버튼 하나로 완료

---

## 기술 스택

| 구분 | 기술 |
|------|------|
| 프론트엔드 | React 18 + Vite + Tailwind CSS |
| 백엔드 | FastAPI (Python) |
| 트랜스크립션 | mlx-whisper (Apple Silicon, 무료) |
| AI 분석 | Claude (claude CLI 통해 호출) |
| 영상 처리 | ffmpeg / ffprobe |

---

## 실행 방법

### 사전 준비

```bash
# ffmpeg 설치 (없다면)
brew install ffmpeg

# mlx-whisper 설치 (Apple Silicon 필요)
pip3 install mlx-whisper --break-system-packages

# Claude Code CLI 설치 (없다면)
npm install -g @anthropic-ai/claude-code
```

### 실행

```bash
cd meeting-edit-ui
./run.sh
```

- 백엔드: http://localhost:8000
- 프론트엔드: http://localhost:5173

## 프로세스

### Step 1 — 영상 선택

영상 파일의 절대경로를 입력하면 ffprobe로 메타데이터를 즉시 불러옵니다.

```
/Users/이름/Desktop/VideoUse/Test/0424_Test.mp4
```

확인되는 정보: 파일명, 길이, 해상도, FPS, 파일 크기, 편집 결과 저장 폴더

---

### Step 2 — 트랜스크립션

mlx-whisper로 영상에서 음성을 텍스트로 변환합니다.

- 모델: `mlx-community/whisper-large-v3-turbo`
- 언어: 한국어
- 소요 시간: 94분 영상 기준 약 30~40분 (M-series Mac)
- 결과: 단어 단위 타임스탬프가 포함된 JSON (캐시 저장)
- 재실행 시 캐시 사용 → 즉시 완료

완료 후 트랜스크립트 전체를 화면에서 검색하며 확인 가능

---

### Step 3 — EDL 편집

편집 결정 목록(EDL)을 만드는 단계입니다. 두 가지 방법이 있습니다.

#### A. AI 자동 분석

상단의 모드를 선택하고 **✦ AI 분석** 버튼을 클릭합니다.

| 모드 | 결과 |
|------|------|
| **전체 편집** | 발표자 화면공유 구간 전체 유지 (원본의 30~40% 수준) |
| **⚡ 쇼츠 10-15분** | 핵심 데모 장면만 선별, 총 10~15분으로 강제 압축 |

Claude가 트랜스크립트를 읽고 약 1~2분 내에 발표자별 구간을 자동으로 채워줍니다.

#### B. 수동 설정

왼쪽 영상 플레이어에서 원하는 시점에 **시작 마크 / 종료 마크** 버튼을 눌러 직접 구간을 추가할 수 있습니다.

AI 결과 위에 추가/수정/삭제도 가능합니다.

**EDL 구조**

```json
{
  "ranges": [
    {
      "source": "영상파일명",
      "start": 462.64,
      "end": 534.78,
      "beat": "발표자명",
      "quote": "대표 발언",
      "reason": "포함 이유"
    }
  ]
}
```

---

### Step 4 — 렌더 & 결과

**렌더 시작** 버튼을 클릭하면 백그라운드에서 ffmpeg가 실행됩니다.

처리 과정:
1. EDL의 각 구간을 원본 영상에서 추출
2. 추출된 클립들을 하나로 이어붙임
3. 오디오 라우드니스 정규화 (-14 LUFS / -1 dBTP)
4. 중간 임시 파일 자동 삭제
5. 편집 보고서 자동 생성

완료 후 화면에서 바로 결과 영상을 재생하고 편집 보고서를 확인할 수 있습니다.

## 결과물

편집이 완료되면 아래 4개 파일만 남습니다.

```
edit_MMDD/
├── preview.mp4       ← 최종 편집 영상 (1080p, H.264, CRF 22)
├── edit_report.txt   ← 편집 보고서
├── edl.json          ← 편집 결정 기록
└── transcripts/
    └── 원본파일명.json ← 트랜스크립트 캐시
```

### 편집 보고서 예시

```
원본 길이:   94분
편집 후 길이: 34.2분 (64% 감소)
클립 수:     25개

발표자별 유지 구간:
  김지석   462~903초   약 4.4분   Word/PDF/HWP → 마크다운 변환 도구
  변지훈   1016~1477초  약 5.1분   구글드라이브 결과서 자동 생성
  전철기   1620~2121초  약 8.4분   AI 뉴스 수집/분석/이메일 발송
  ...
```

## 편집 기준

**유지하는 것**
- 발표자가 화면공유를 켜고 직접 설명하는 구간
- 발표 내용 이해에 필수적인 Q&A (도구 형태 명확화, 핵심 기능)

**제거하는 것**
- 사회자 오프닝 / 발표자 소개 / 전환 / 마무리
- 발표 후 사회자 방향 제시, 권장 발언
- Q&A 중 비용·운영·기술 세부 논의
- 음향 설정, 화면공유 준비 지연
- 필러워드 단독 발화 ("어", "음", "네네네" 반복)

---

## 제한 사항

- **Apple Silicon 필수**: mlx-whisper가 M-series Mac에서만 작동합니다
- **로컬 전용**: 영상 파일은 로컬 디스크에 있어야 합니다
- **화자 분리 없음**: 트랜스크립션은 전체를 단일 화자로 처리하고, AI가 내용 기반으로 발표자를 구분합니다
- **한국어 최적화**: 영어 영상도 동작하지만 편집 프롬프트가 한국어 기준입니다
